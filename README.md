# 🏢 HR Attrition & Employee Analytics Dashboard

This project explores the IBM HR Analytics Employee Attrition & Performance dataset using **PostgreSQL**, **Python (Pandas)**, and **Power BI** to uncover key factors driving employee turnover and retention.

## 🛠️ Tech Stack & Tools Used
* **Database & Querying:** PostgreSQL, pgAdmin 4 (Data cleaning, schema alignment, and SQL analytical queries)
* **Data Processing:** Python (Pandas, NumPy for data manipulation, `pd.cut`, and grouping)
* **Visualization:** Power BI Desktop (Interactive metrics, dark-themed modern UI, KPI cards)
* **Version Control:** Git & GitHub

---

## 🔍 Key Business Questions Addressed
1. **Overtime Impact:** Do employees working overtime exhibit a significantly higher attrition rate?
2. **Salary Brackets:** How does monthly income distribution affect employee retention (`Low`, `Medium`, `High` income brackets)?
3. **Job Satisfaction:** What is the correlation between employee satisfaction levels (Scale 1-4) and voluntary resignations?
4. **Commute Distance:** Does a longer distance from home increase the likelihood of leaving the organization?

---

## 📂 Repository Structure
* `hr_analytics_cleaned.csv` -> Processed and cleaned dataset ready for visualization
* `hr_analytics_cleaning.py` -> Python script for handling missing values and data preprocessing
* `hr_analytics_queries.sql` -> SQL queries for database management, data hygiene, and metrics calculation
* `HR_Attrition_Dashboard.pbix` -> Power BI Dashboard File

---

## 🚀 Key Insights & Findings
* **Overtime Risk:** Employees engaged in consistent overtime show a substantially higher churn rate compared to regular hours.
* **Income Trend:** Lower income brackets experience greater attrition, emphasizing the need for competitive compensation structures in entry-level bands.
* **Satisfaction Scale:** Lower job satisfaction ratings strongly correlate with increased employee turnover.
